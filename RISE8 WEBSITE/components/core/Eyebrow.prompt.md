Uppercase, letter-spaced Inter label that sits above a headline or names a section — the brand's eyebrow/kicker. Use `number` to prefix the almanac-style index with an accent middot.

```jsx
<Eyebrow number="02">Our platform</Eyebrow>
<Eyebrow size="sm" onDark>Stayable</Eyebrow>
```

Sizes: `lg` (11px), `md` (10px), `sm` (9px). Set `onDark` on navy surfaces.
