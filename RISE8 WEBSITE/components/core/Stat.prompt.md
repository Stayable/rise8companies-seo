Headline statistic: a big EB Garamond figure with an optional teal superscript unit, over an uppercase Inter label. Use in a 4-column grid for the stats band.

```jsx
<Stat value="1,300" sup="+" label="Keys managed" />
<Stat value="100" sup="%" label="Stayable branded" />
```

Set `onDark` when placed on navy. Keep figures real — don't invent stats to fill a grid.
