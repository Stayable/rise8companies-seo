Home — "Tell the RISE8 story on first scroll"

3 distinct structural approaches · desktop + mobile

Goal

What should Home accomplish?

Explain that RISE8 is a parent holding 4 affiliated companies, prove scale quickly (1,300+ keys, 7 properties), and give investors + guests + operators each a clear next step.

What varies across the 3 options

  • V1 — Conventional: hero → metrics → 4-tile platform → featured props.
  • V2 — "Holding company" framing: parent/child family tree dominates the fold.
  • V3 — Bold swing: a single vertical list of companies as the hero.

Stats · map · property cards → Stayable booking

Goal

Two audiences, one page.

Investors want scale + markets; travelers want to find a property near them and click "Book." The three options differ on which audience leads.

What varies

  • V1 — Stats → map → grid (spec-accurate).
